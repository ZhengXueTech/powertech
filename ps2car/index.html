PS2 小車　安裝與使用指南

用 PS2 手把遙控你的 Arduino 小車。這一頁會帶你從「下載工具包」一路做到「手把能開車」，照著五個步驟走就好，全部完成大約 20～30 分鐘。

1

下載並解壓縮工具包

  1. 點上面的「下載工具包」，取得 PS2_Car_tool_efun.zip。
  2. 在檔案上按右鍵，選「全部解壓縮」（不要直接在壓縮檔裡面點開檔案使用）。
  3. 解壓縮後，你會看到這樣的內容：
PS2_Car_tool_efun/
├─ PS2控制配置台.html     ← 網頁設計工具（第 3 步用）
├─ 使用說明.txt
└─ PS2Car/                ← Arduino 專案資料夾（第 4 步用）
   ├─ PS2Car.ino          ← 你的程式會放在這裡
   └─ 其他 .h / .cpp      ← 控制板需要的檔案，請不要刪除
⚠ 重要：名稱不要改成中文

PS2Car 資料夾和裡面的 PS2Car.ino 一定要用英文，而且兩個名字要一模一樣。改成中文的話，Arduino 會跳出「Invalid sketch name」打不開。

💡 小提醒

整個 PS2Car 資料夾要一起使用，不能只複製 PS2Car.ino 一個檔案出來，否則編譯時會找不到其他檔案。

2

安裝 Arduino IDE

Arduino IDE 是把程式「燒進」控制板的軟體。很多人卡在這一步：沒裝它，後面的程式就送不進車子。電腦裡已經有就可以跳過。（以下以 Windows 為例）

⬇ 前往 Arduino 官方下載頁

  1. 點上面的按鈕（或到 arduino.cc/en/software），下載 Windows 版安裝檔。下載頁可能會問要不要捐款，直接點「Just Download」即可，不用付費。
  2. 執行安裝檔，一路按「下一步」直到完成。

你不需要另外安裝任何函式庫，需要的檔案都已經放在 PS2Car 資料夾裡了。

可能要裝：CH340 驅動程式

第一次把控制板用 USB 接上電腦後，如果在 Arduino IDE 的「工具 → 連接埠」裡完全沒有 COM 埠，或是「裝置管理員」出現黃色驚嘆號／「不明裝置」，就是缺驅動：

  1. 搜尋並安裝「CH340 driver」（免費的常見驅動程式）。
  2. 裝好後把 USB 線拔掉再重新插上。
💡

Windows 有時會自己裝好驅動，連接埠出現了就不用再裝。

3

用「PS2 控制配置台」設計控制方式

用 Chrome 或 Edge 直接打開解壓縮資料夾裡的 PS2控制配置台.html（不用安裝、不用網路）。也可以直接用網頁版配置台，功能一樣。你要做的事就是告訴它：手把哪個按鍵／搖桿，要控制哪個馬達或伺服機，它會幫你寫好 Arduino 程式。

① 選驅動模式

遙控車模式戰車模式手動模式
  • 遙控車模式：像開車——左搖桿前後控制前進後退，右搖桿左右控制轉彎。
  • 戰車模式：像履帶戰車——左搖桿控制左輪，右搖桿控制右輪，各自獨立。
  • 手動模式：搖桿不自動開車，全部由你自己指定。（這個模式不會有燈號與蜂鳴器）

選好後，下面會出現「左輪馬達／右輪馬達」的選單，選你車子實際接的馬達。

② 設定按鍵對應

在手把圖上點一個按鍵（或搖桿軸），再選它要做什麼，例如「按住 ○ 時，伺服機轉到 35 度」「按住 R2 時，馬達 M3 前進」。設定好之後，右邊／下方就會即時更新程式碼。

③ 常用的進階設定

搖桿死區　Y 軸 ±20
進階　▸ 練習模式（限速，適合新手）　▸ 方向鍵即時切換模式
設定用途
搖桿死區搖桿放開時很難剛好回到正中間。死區範圍內的小晃動都當作「沒推」。車子在原地抖動、爬行時，把死區調大；覺得搖桿要推很多才會動，就調小。建議從預設 ±20 開始。
練習模式（限速）勾選後可以拉桿設定「最高速度上限」（預設 60%）。新手剛開始建議開著，車子不容易失控撞牆。練習夠了要取消勾選，重新產生程式碼並上傳，才會恢復全速。
方向鍵即時切換模式預設是開啟。比賽中不用重新上傳，按手把的方向鍵就能在「遙控車」與「戰車」模式間切換（見第 5 步）。

④ 取得程式碼

設定完成後，按「複製程式碼」，或按「下載程式碼」存成檔案。

💡 記得備份

瀏覽器通常會記住你上次的設定，但不保證。每次設計完，請把程式碼複製或下載保存起來，不要只靠瀏覽器記憶。

4

貼進 PS2Car.ino 並上傳到控制板

  1. 打開 Arduino IDE，選單「檔案 → 開啟」，選到 PS2Car 資料夾裡的 PS2Car.ino。
  2. 在程式編輯區按 Ctrl+A 全選，按 Delete 刪掉原本內容，再按 Ctrl+V 貼上剛剛複製的程式碼，存檔（Ctrl+S）。
    （如果你是下載成檔案，打開後全選複製，貼進 PS2Car.ino 一樣的做法。）
  3. 用 USB 線把控制板接上電腦。
  4. 選單「工具 → 開發板」選 Arduino Uno。
  5. 選單「工具 → 連接埠」選出現的那個 COM 埠。（沒有的話回第 2 步檢查 CH340 驅動。）
  6. 按左上角的 「→」上傳鍵，等下方訊息列顯示「上傳成功」。上傳時板子燈閃爍是正常的。
⚠ 上傳前先確認

如果有模組接在控制板的 0、1 腳位（RX/TX），上傳可能失敗。先把那兩個腳位的線拔掉，上傳成功再接回去。

💡 以後改設定

每次在配置台改了設定，都要重新複製程式碼 → 貼上 → 上傳，車子才會用新設定。

5

開機看燈號，測試手把

控制板上有內建的 RGB 彩色燈和蜂鳴器，不用另外接線。燈號可以讓你一眼看出車子現在的狀態。

開機後會看到

暗紫燈（約半秒）
表示新版程式啟動了
➜
紅燈　戰車模式
（預設起始模式）

紫燈之後亮的顏色，就是配置台裡選的「起始模式」：紅燈＝戰車模式、綠燈＝遙控車模式。

如果老師要你把幾台車放在一起，配置台的「進階：呼吸燈車號」可以選 1～4 號：燈會慢慢呼吸（戰車＝深紅到粉紅、遙控車＝深綠到淺綠），車號越大呼吸越快，顏色還是代表模式。手把斷線煞車時，燈會改成急促閃紅。

用方向鍵切換模式

戰車模式
按手把 方向鍵下　低音嗶一聲
⇄
遙控車模式
按手把 方向鍵上　高音嗶一聲

切換成功時，燈色會立刻改變並發出短短的「嗶」聲。（這需要配置台的「方向鍵即時切換模式」保持開啟，預設就是開的。）

看到的情況代表什麼／怎麼辦
開機有閃暗紫燈新版程式有成功上傳 👍
沒有紫燈，一開機就是綠燈可能還是舊版程式，或這次上傳沒成功。重新上傳一次。
完全沒有燈確認電池／電源有接好、電源開關有打開。若配置台選的是「手動模式」，本來就不會有燈號。
車子開著開著突然停住手把和接收器之間斷線了（可能手把沒電或離太遠）。程式會自動讓所有馬達煞車，訊號恢復後就會繼續動，不用重開機。

測試順序建議

  1. 先把車子架高，讓輪子離地，避免一開機就衝出去。
  2. 打開手把電源，等它和接收器連上。
  3. 推左／右搖桿，看輪子轉動方向對不對；按各個按鍵，看馬達與伺服機有沒有照你設定動作。
  4. 都正常了再放到地上開。

🔌 接線與硬體提醒

電源

  • 本機使用 2 顆 18650 鋰電池串聯供電（滿電約 8.4 V）。
  • 電源接在板子的「電源接線柱」（螺絲鎖固式端子），不是小插頭。正負極不要接反，螺絲要鎖緊，線頭不要鬆脫。
  • 只接 USB 線通常可以上傳程式，但馬達需要接上電池才會動。
🔋 馬達沒力、時動時不動，先量電池電壓！

電壓不夠時，馬達會無力或動不起來，看起來很像「接線接錯了」。遇到這種狀況，先用三用電表量電池電壓，再來檢查接線。

兩顆電池串聯，電壓低於約 6.4 V 就先充電或換電池，不要硬用。（電池要完整充電、同時使用的兩顆最好是同一批。）

馬達與伺服機

  • 直流馬達接在板子的 M1～M4 端子。左右輪實際接哪一個，要和配置台「左輪馬達／右輪馬達」選的一致。
  • 伺服機接在標示 1～8 的插座。配置台裡的「伺服機表」會標示每個名稱對應的插槽號碼，照表接。
  • 伺服機插頭有方向性，對照板子上的標示插，不要反插。
  • 輪子方向相反（推前進卻後退）：在馬達端子上把該顆馬達的兩條線對調就會反過來；或在配置台改選左右輪馬達。

內建的燈與蜂鳴器

RGB 燈（接在 A1）和蜂鳴器（接在 A0）都是板子內建的，不需要外接。請不要把其他零件接在 A0、A1 上。

🎮 預設範本的按鍵對應

工具包預設的設定長這樣。你在配置台改過之後就會不一樣，以你下載的程式碼為準。

❓ 常見問題

打開專案時跳出「Invalid sketch name」

資料夾名稱或 .ino 檔名含有中文、空格，或兩個名字不一樣。請把資料夾和檔案都改成英文且完全相同（例如 PS2Car 與 PS2Car.ino）。

編譯時出現一大堆「找不到 xxx.h」

通常是只複製了 PS2Car.ino 單一檔案。請確認你打開的 PS2Car.ino 旁邊還有 Emakefun_MotorDriver.h、PS2X_lib.h 等一整批檔案；也不要在 zip 壓縮檔裡面直接打開，要先「全部解壓縮」。

上傳時出現 avrdude: stk500_recv(): programmer is not responding

大多是以下兩種原因：

  • 「連接埠」選錯了，重新在「工具 → 連接埠」選對 COM 埠、「開發板」選 Arduino Uno。
  • 0、1 腳位（RX/TX）接了模組干擾上傳。把那兩個腳位的線先拔掉，上傳成功再接回去。
「連接埠」選單裡完全沒有 COM 埠

通常是沒裝驅動。依第 2 步安裝「CH340 driver」，裝完把 USB 拔掉再插上。也可以換一條 USB 線試試（有些線只能充電，不能傳資料）。

上傳成功了，但車子完全不動

依序檢查：

  1. 開機有沒有看到暗紫燈？沒有的話，程式可能沒上傳成功。
  2. 手把電池有電嗎？手把電源有打開、和接收器連上了嗎？
  3. PS2 接收器有插好嗎？
  4. 電池有接好、電壓夠嗎？（見「接線與硬體提醒」，先量電壓。）
  5. 配置台裡該按鍵有真的設定對應的馬達嗎？
馬達沒力、一加速就卡住或板子重開

最常見的原因是電池電壓不夠。請用三用電表量電池電壓，低於約 6.4 V 就先充電或換電池，再來懷疑接線。也可以打開練習模式降低最高速度，測試看看是否比較穩定。

我的手把好像連到別組的車

很多組同時使用時，手把可能連到別台車的接收器。請在測試時一次只開自己組的手把，確認你按按鍵時是自己的車有反應；其他組先關掉手把電源。不確定時請老師協助。

左右輪方向相反，或前進變後退

兩個辦法擇一：在馬達端子上把那一顆馬達的兩條線對調；或在配置台的「左輪馬達／右輪馬達」改選。改完配置台記得重新複製、貼上、上傳。

車子在搖桿放開時還是會抖動或慢慢爬

把配置台的「搖桿死區」調大一點（例如 ±25～±30），重新產生程式碼並上傳。

怎麼把練習模式（限速）關掉？

在配置台「進階：練習模式」取消勾選，重新複製程式碼、貼進 PS2Car.ino、再上傳一次，車子就會恢復全速。

關掉瀏覽器，配置台的設定會不見嗎？

通常不會，但不保證。為了保險，每次設計完請把程式碼複製或下載備份。
