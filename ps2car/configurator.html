PS2 GAMEPAD · EMAKEFUN MOTOR DRIVER

PS2 控制配置台

點手把上的按鍵或搖桿，設定它要控制哪顆馬達或伺服馬達，右邊會即時產生可以直接貼進 Arduino IDE 的 .ino 程式碼。

安裝與使用前準備 第一次用這個工具的話，建議先看過這裡，之後可以收合起來

一、下載 Arduino IDE

  1. 到 Arduino 官方下載頁：arduino.cc/en/software，依你的作業系統（Windows／macOS）下載安裝檔並安裝。
  2. 用 USB 接上擴充板後打開 Arduino IDE，到「工具 → 開發板」選對應的板子（例如 Arduino Uno），「工具 → 序列埠」選正確的連接埠，才能燒錄。

二、載入這台車專用的函式庫

這片 Emakefun 擴充板用的函式庫不是從「函式庫管理員」搜尋安裝的，而是要把檔案跟 .ino 放在同一個資料夾，Arduino IDE 才會一起編譯進去。

  1. 建立一個新資料夾，名稱要跟下載的 .ino 檔名完全相同（例如 PS2Car_generated）——Arduino 規定 sketch 資料夾名稱跟 .ino 檔名都只能用英文字母、數字、底線、破折號（不能有中文或空格），而且兩者要完全一致，不一樣的話 IDE 會要你另存新檔或跳出「Invalid sketch name」錯誤。
  2. 把上面「下載 .ino」拿到的檔案放進這個資料夾。
  3. 把下面這 12 個檔案，從這個工具包資料夾裡整份複製到同一個資料夾：
Emakefun_MotorDriver.hEmakefun_MotorDriver.cpp Emakefun_MS_PWMServoDriver.hEmakefun_MS_PWMServoDriver.cpp PS2X_lib.hPS2X_lib.cpp IRremote.hIRremote.cpp keymap.hKeymap.cpp Buzzer.hBuzzer.cpp RGBLed.hRGBLed.cpp Sounds.h nRF24L01.hnRF24L01.cpp PinChangeInt.h
  1. 用 Arduino IDE 打開資料夾裡的 .ino，按左上角「✓」驗證編譯，沒有紅字錯誤就可以燒錄了。

這 12 個檔案就是完整的一組，不需要另外安裝 Makeblock 或其他官方函式庫。只要把上面這份清單跟 .ino 放進同一個資料夾，換到全新的電腦、只裝 Arduino IDE 也能直接編譯。

進階：練習模式（限速，適合新手）
60%

開啟後，產生／下載的程式會把所有馬達速度都壓在這個百分比以內，讓新手先熟悉操作手感，練習夠了再關掉這個選項、下載全速版本。

進階：呼吸燈車號（多台車放一起時分辨用）

開啟後，車上的燈會慢慢「呼吸」：戰車模式是深紅到粉紅，遙控車模式是深綠到淺綠，顏色仍然代表模式，呼吸快慢代表車號。兩台車放在一起時，看呼吸節奏就分得出來。手把斷線煞車時，燈會改成急促閃紅。沒勾選就維持原本的恆亮紅燈或綠燈。

需要使用「遙控車模式」或「戰車模式」才有燈號；選「手動」模式時沒有模式燈，這個選項不會有作用。

進階：方向鍵即時切換模式

開啟後可以用方向鍵在兩種模式之間即時切換，不用重新燒錄程式；兩種模式各自用自己上面設定的馬達與死區。
