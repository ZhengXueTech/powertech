T-Display 藍牙遙控器　安裝與使用指南

把 LILYGO T-Display 做成清道達人的實體遙控器：不靠手機、不怕斷網、按住才動、放開就停。照著六個步驟走，第一次大約 30～40 分鐘。

⬇ 下載程式（PowerTech_TDisplay.zip） 🔧 還沒裝 Arduino IDE？先到這裡下載 從第 1 步開始
適用：LILYGO T-Display（ESP32，V1.1）。T-Display S3 版本開發中。

⚠ 比賽使用前先確認

材料供應商（思頂創客）回覆：可以不用原廠 App、可以用 ESP32 等電子零件自製遙控器，但現成的控制器（掌機、市售手把）不符合自製。競賽規則最終以主辦單位公告為準，正式比賽前請再確認一次。

1

下載並解壓縮程式

  1. 點上面的「下載程式」，取得 PowerTech_TDisplay.zip。
  2. 在檔案上按右鍵，選「全部解壓縮」。
PowerTech_TDisplay/
└─ PowerTech_TDisplay.ino   ← 用 Arduino IDE 打開這個檔案
⚠ 名稱不要改

資料夾和 .ino 檔名必須一模一樣、而且是英文，否則 Arduino 會出現「Invalid sketch name」。

2

安裝 Arduino IDE 與 ESP32 開發板

  1. 到 arduino.cc/en/software 下載 Arduino IDE 2.x，一路按「下一步」安裝。
  2. 打開 Arduino IDE，選「檔案 → 偏好設定」，在「額外的開發板管理員網址」貼上：
    https://espressif.github.io/arduino-esp32/package_esp32_index.json
  3. 點左側「開發板管理員」圖示，搜尋 esp32，找到 Espressif Systems 那一項。
  4. 版本下拉選單選 2.0.17，再按「安裝」。
✖ 不要裝最新的 3.x 版

螢幕函式庫 TFT_eSPI 搭配 3.x 常出現編譯錯誤或開機一直重啟。之後 IDE 右下角跳出「有可用更新」也不要按。

可能要裝：USB 驅動程式

用 USB-C 線接上 T-Display 後，如果「工具 → 連接埠」沒有任何 COM 埠，請搜尋安裝「CH9102 driver」或「CH343 driver」（沁恆 WCH 官網），裝完拔掉再插。若還是沒反應，可能是線只能充電不能傳資料，換一條試試。

3

安裝並設定螢幕函式庫 TFT_eSPI

  1. 點左側「程式庫管理員」，搜尋 TFT_eSPI（作者 Bodmer），按「安裝」。
  2. 用檔案總管打開：文件\Arduino\libraries\TFT_eSPI\
  3. 用記事本開啟 User_Setup_Select.h，改兩行：
    • #include <User_Setup.h> 前面加上 //
    • 找到 //#include <User_Setups/Setup25_TTGO_T_Display.h>，把前面的 // 刪掉
  4. 存檔。
//#include <User_Setup.h>                          ← 加上 //
#include <User_Setups/Setup25_TTGO_T_Display.h>     ← 拿掉 //
💡 這步沒做會怎樣？

程式能上傳，但螢幕全黑。這是最常見的問題。

4

選開發板與分割方式

打開 PowerTech_TDisplay.ino，在「工具」選單設定：

項目設定
開發板ESP32 Arduino → ESP32 Dev Module
Partition SchemeHuge APP (3MB No OTA/1MB SPIFFS)
連接埠插上 T-Display 後出現的 COM 埠
其他項目維持預設
⚠ Partition Scheme 一定要改

藍牙加螢幕的程式超過預設的 1.2MB，不改會出現「Sketch too big」。

5

上傳程式

  1. 按左上角 ✓ 編譯，第一次會比較久。
  2. 編譯成功後按 → 上傳。下方會跑出 Writing at …，最後出現 Hard resetting 就完成了。
  3. 板子會自動重開，螢幕出現 SCANNING…。
💡 卡在 Connecting……？

按住板子正面左鍵（BOOT）再按上傳，看到 Writing 開始跑就放開。

6

選車、連線、測試

  1. 小車開電，手機原廠 App 斷線（最好直接關掉手機藍牙）。
  2. T-Display 開機會掃描 3 秒，列出附近的藍牙裝置，訊號最強的排最上面。
  3. 左鍵選到自己的車（PT- 開頭），按右鍵連線。
  4. 螢幕出現綠色 CONNECTED，小車藍牙燈變恆亮，就可以開車了。
💡 下次開機

會自動選好上次連過的車，直接按右鍵就能連。

⚠ 第一次測試

先把車架高讓輪子懸空，確認前進後退方向正確。方向相反時，把該顆馬達的兩條線對調即可。

接線：外接按鍵

不接任何按鍵也能用：板上左鍵 = 左輪前進、右鍵 = 右輪前進。要完整控制就外接 8 顆按鍵（12×12 輕觸開關）。

功能T-Display 腳位清道達人
左輪 前進G25M4
左輪 後退G26M4
右輪 前進G27M1
右輪 後退G33M1
滾刷 收球G21M2
滾刷 吐球G22M2
後門 ＋G17M3
後門 −G13M3
所有按鍵的另一腳GND—
💡 開關為什麼要接「對角線」？

輕觸開關 4 支腳兩兩一組、本來就相通，按下時才把兩組接起來。對角線的兩支腳一定屬於不同組，所以一支接 GPIO、對角另一支接 GND，就一定是「按下才導通」。

⚠ 不需要電阻

程式會開啟晶片內建的上拉電阻。按鍵絕對不要接到 3V3 或 5V。

操作方式

畫面操作動作
選車左鍵 短按往下選
左鍵 長按 1 秒重新掃描
右鍵 短按連線
駕駛按住按鍵對應馬達轉動，放開就停
左右前進一起按直走；一前一後 = 原地轉
側邊 RST 鍵重新開機，回到選車畫面（換車用）

斷線時會每 3 秒自動重連同一台車。

常見問題

螢幕全黑

第 3 步 User_Setup_Select.h 沒改好，或改完沒存檔。改完要重新上傳。

出現「Sketch too big」

第 4 步 Partition Scheme 沒改成 Huge APP。

上傳卡在 Connecting……

按住正面左鍵（BOOT）再上傳；或換一條能傳資料的 USB 線。

一直 SCANNING，清單裡找不到車

小車有開電嗎？手機原廠 App 是不是還連著？小車一次只能被一個裝置連線。長按左鍵 1 秒重新掃描。

連上了但車子不動

確認按鍵接的是對角腳、另一腳有接 GND。可以打開 Arduino「序列埠監控窗」（115200），按鍵時會顯示送出的位元組，例如 送出 80。

編譯錯誤很多、或開機一直重啟

ESP32 開發板版本不是 2.0.17。回到第 2 步改版本。
