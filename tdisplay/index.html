萬用遙控器（T-Display）　安裝與使用指南

把 LILYGO T-Display 做成清道達人的自製遙控器：螢幕選車、按住才動、設定存在板子裡；開 Wi-Fi 熱點後，iPhone、iPad、Android 都能用瀏覽器控制，不用裝 App、不需要網路。第一次照著做大約 40 分鐘。

⬇ 下載程式（UniRemote v0.2） 🔧 還沒裝 Arduino IDE？先到這裡下載 從第 1 步開始
已實測：LILYGO T-Display V1.1（ESP32）。同一份程式也支援 T-Display S3（實機測試中）。

⚠ 比賽使用前先確認

材料供應商（思頂創客）回覆：可以不用原廠 App、可以用 ESP32 等電子零件自製遙控器，但現成的控制器（掌機、市售手把）不符合自製。競賽規則最終以主辦單位公告為準，正式比賽前請再確認一次。

1

下載並解壓縮程式

  1. 點上面的「下載程式」，取得 UniRemote_v0.2.zip。
  2. 在檔案上按右鍵，選「全部解壓縮」。
UniRemote_v0.2/
├─ UniRemote/
│  ├─ UniRemote.ino   ← 用 Arduino IDE 打開這個檔案
│  ├─ types.h
│  ├─ assets.h        （中文字型）
│  ├─ web.h           （手機控制頁）
│  ├─ qrcodegen.c
│  └─ qrcodegen.h
├─ tools/             （改中文字時才用得到）
└─ 使用說明.txt
⚠ 6 個檔案要放在一起

UniRemote 資料夾裡的檔案都要在，資料夾名稱和 .ino 檔名也不要改。打開後 Arduino IDE 上方會出現好幾個分頁，這是正常的。

2

安裝 Arduino IDE 與 ESP32 開發板

  1. 到 arduino.cc/en/software 下載 Arduino IDE 2.x，一路按「下一步」安裝。
  2. 打開 Arduino IDE，選「檔案 → 偏好設定」，在「額外的開發板管理員網址」貼上：
    https://espressif.github.io/arduino-esp32/package_esp32_index.json
  3. 點左側「開發板管理員」圖示，搜尋 esp32，找到 Espressif Systems 那一項。
  4. 版本下拉選單選 2.0.17，再按「安裝」。
✖ 不要裝最新的 3.x 版

螢幕函式庫 TFT_eSPI 搭配 3.x 常出現編譯錯誤或開機一直重啟。之後 IDE 右下角跳出「有可用更新」也不要按。

藍牙、Wi-Fi、網頁伺服器都是 ESP32 內建的，不用另外安裝其他函式庫（螢幕函式庫在下一步）。

可能要裝：USB 驅動程式

用 USB-C 線接上 T-Display 後，如果「工具 → 連接埠」沒有任何 COM 埠，請搜尋安裝「CH9102 driver」或「CH343 driver」（沁恆 WCH 官網），裝完拔掉再插。若還是沒反應，可能是線只能充電不能傳資料，換一條試試。

3

安裝並設定螢幕函式庫 TFT_eSPI

  1. 點左側「程式庫管理員」，搜尋 TFT_eSPI（作者 Bodmer），按「安裝」。
  2. 用檔案總管打開：文件\Arduino\libraries\TFT_eSPI\
  3. 在 User_Setup_Select.h 上按右鍵 →「開啟檔案」→ 選記事本。
  4. 按 Ctrl+F 搜尋，依你的板子改成下面這樣（前面有 // 代表不使用），存檔。

T-Display V1.1（ESP32，小螢幕 1.14 吋）

//#include <User_Setup.h>                                 ← 前面加 //
#include <User_Setups/Setup25_TTGO_T_Display.h>            ← 前面的 // 刪掉
//#include <User_Setups/Setup206_LilyGo_T_Display_S3.h>   ← 保持有 //

T-Display S3（大螢幕 1.9 吋）

//#include <User_Setup.h>
//#include <User_Setups/Setup25_TTGO_T_Display.h>          ← 加回 //
#include <User_Setups/Setup206_LilyGo_T_Display_S3.h>     ← 前面的 // 刪掉
💡 原則

整個檔案裡，開頭是 #include <User_Setup 而且前面沒有 // 的，只能有一行。這步沒做好，程式能上傳但螢幕全黑。

4

選開發板與分割方式

打開 UniRemote.ino，在「工具」選單設定：

開發板ESP32 Dev ModuleESP32S3 Dev Module
Partition SchemeHuge APP (3MB No OTA/1MB SPIFFS)
USB CDC On Boot（沒有這項）Enabled
Flash Size預設16MB (128Mb)
PSRAM（沒有這項）OPI PSRAM
連接埠插上板子後出現的 COM 埠
⚠ Partition Scheme 一定要改，而且換開發板會被重設

程式含藍牙、Wi-Fi 和中文字型，約 2MB，超過預設的 1.25MB，不改會出現「Sketch 太胖了」。每次切換開發板之後都要再檢查一次。

5

上傳程式

  1. 按左上角 → 上傳。第一次編譯比較久（1～3 分鐘）。
  2. 下方跑出 Writing at …，最後出現 Hard resetting 就完成了。
  3. 板子自動重開，螢幕出現「學思創客 萬用遙控器」，接著進入駕駛畫面。
💡 卡在 Connecting……？

按住板子的 BOOT 鍵，按一下 RST 再放開 BOOT，然後重新上傳。上傳完按一下 RST，程式就會開始跑。

💡 出現「找到了多個 BLEDevice.h 程式庫」

這只是提醒，不是錯誤。它會用 ESP32 內建的藍牙，這就是對的。

6

第一次選車、連線

沒有接任何外部按鍵也能完成，只用板子上的兩顆鍵（左鍵、右鍵）。

  1. 小車開電，手機原廠 App 要先斷線（小車一次只能連一個裝置）。
  2. 在駕駛畫面長按右鍵 1 秒，下方跑完進度條就會進入「設定選單」。
  3. 選「連線」→ 右鍵短按 →「選擇小車」→ 右鍵短按，掃描約 3 秒。
  4. 清單依訊號強弱排序，最上面通常就是最近的車。左鍵移到你的車，右鍵短按連線。
  5. 連上後回到駕駛畫面，標題列右邊出現車名。
💡 之後開機

會自動連上次那台車；斷線會自動重連 3 次。還是連不上時，在駕駛畫面短按右鍵再試一次。

7

檢查馬達與方向

① 單顆馬達測試：確認每顆都會轉

  1. 選單 →「馬達設定」→ 往下到「單顆馬達測試」→ 右鍵短按。
  2. 按住右鍵：選中的馬達轉，放開就停。左鍵短按換下一顆，左鍵長按離開。
  3. M1～M4 逐顆測，記下每顆是哪個輪子或機構。

這個畫面只看「會不會轉」，不套用反轉設定，所以方向要在駕駛畫面檢查。

② 駕駛畫面：確認方向

先把車架高，讓輪子懸空。用一條杜邦線，一端插 GND，另一端去碰下面的腳位（碰到就等於按下那顆鍵）：

碰這支腳（V1.1）應該看到不對的話
G25 左輪▲左輪往車頭方向滾選單 → 馬達設定 →「左輪反轉」改成開
G27 右輪▲右輪往車頭方向滾「右輪反轉」改成開
G21 滾刷收滾刷把球往車內捲「滾刷反轉」改成開
G17 後門＋後門打開「後門反轉」改成開
💡 動到別的馬達？

表示接到別的埠，到「左輪 接 M?」這類項目，右鍵短按就會換成下一個埠。被搶走的功能會自動換到空出來的埠，不會重複。設定會存在板子裡，拔電也不會忘。

最後放回地上，同時碰 G25 和 G27，車子應該直線前進。

8

用手機或平板控制

遙控器開機後會自己開一個 Wi-Fi 熱點。手機連上這個 Wi-Fi，用瀏覽器打開控制頁，遙控器再用藍牙轉給小車。不需要網路、不用裝 App。

📱 手機／平板
瀏覽器
→ Wi-Fi →
📟 萬用遙控器
PowerTech-XXXX
→ 藍牙 →
🚗 清道達人
  1. 駕駛畫面最下面會顯示「手機配對碼 1234」（每次開機都不一樣）。
  2. 選單 →「手機連線」→「顯示 QR Code」。
    • 第 1 頁：用手機相機掃描 → 加入 Wi-Fi（PowerTech-XXXX，密碼 ccjhsmaker）
    • 第 2 頁（左鍵切換）：掃描 → 打開控制頁。也可以在瀏覽器輸入 192.168.4.1
  3. 在控制頁輸入配對碼 → 按「開始控制」。
  4. 手機橫放：左手按左輪、右手按右輪，中間是收球、吐球、滾刷常開、後門。可以多指同時按。
⚠ 手機說「此 Wi-Fi 沒有網際網路」

選「保持連線」。如果控制頁一直打不開，先把行動數據關掉再試。

安全設計

  • 一次只有一支手機能控制，其他人輸入配對碼會被拒絕。
  • 要換人：選單 →「手機連線」→「換碼踢掉手機」，舊手機立刻失去控制，用新配對碼重新連。
  • 手機訊號斷掉、切到別的 App、關螢幕：0.4 秒內小車自動停。
  • 遙控器在選單裡時，小車一律停；手機頁會顯示提示。
  • 手機只能開車，不能改馬達設定。方向和埠的設定一律在遙控器上改，手機自動照著走。
操作來源（選單 → 手機連線）說明
混合（預設）實體鍵和手機都可以開車
實體鍵手機不能控制（比賽只用實體遙控器時）
手機只有手機能開車；遙控器只當轉接盒

不需要手機時，可以在「手機連線 → Wi-Fi 熱點」關掉，比較省電。Wi-Fi 密碼可以在程式最上面的 AP_PASS 修改（至少 8 碼、建議全小寫）。

💡 開關為什麼要接「對角線」？

12×12 輕觸開關的 4 支腳兩兩一組、本來就相通，按下時才把兩組接起來。對角線的兩支腳一定屬於不同組，所以一支接 GPIO、對角另一支接 GND，就一定是「按下才導通」。

⚠ 不需要電阻

程式會開啟晶片內建的上拉電阻。按鍵絕對不要接到 3V3 或 5V。接好後到選單「按鍵測試」逐顆確認。

常見問題

螢幕全黑

第 3 步 User_Setup_Select.h 沒改好、改完沒存檔，或選了別塊板子的設定檔。改完要重新上傳。

出現「Sketch 太胖了」「本文區已超出開發板的可用空間」

Partition Scheme 沒改成 Huge APP。切換過開發板之後要再設一次。

出現「This chip is ESP32 not ESP32-S3」

插的是 V1.1（ESP32），開發板卻選了 ESP32S3。改選 ESP32 Dev Module，螢幕設定檔也要換成 Setup25。反過來的錯誤訊息就是換成 S3 的設定。

出現「'Car' does not name a type」

用到舊版程式了。請重新下載最新的 zip，確認資料夾裡有 types.h。

選擇小車時找不到車

小車有開電嗎？手機原廠 App 或手機網頁遙控器是不是還連著？小車一次只能被一個裝置連線。在空清單畫面按右鍵重新掃描。

手機控制頁打不開

確認手機的 Wi-Fi 連的是 PowerTech-XXXX（不是學校 Wi-Fi）；跳出「沒有網際網路」要選保持連線；關掉行動數據再開 192.168.4.1。也確認選單裡「Wi-Fi 熱點」是開的。

手機顯示「已有其他手機在控制」

同一時間只有一支手機能控制。請原本的手機關掉控制頁，等 3 秒再試；或在遙控器選單「換碼踢掉手機」。

用手機開車時一頓一頓

控制頁右上角會顯示延遲（ms）。數字常常跳到幾百，表示 Wi-Fi 不穩：靠近遙控器一點、避開很多人同時開熱點的地方。訊號斷掉超過 0.4 秒，小車會先停下來保護安全。

編譯錯誤很多、或開機一直重啟

ESP32 開發板版本不是 2.0.17。回到第 2 步改版本。

想看遙控器送了什麼指令

打開 Arduino「序列埠監控視窗」，速率選 115200。按鍵時會印出 TX 82 這類位元組，開機時也會印出 Wi-Fi 名稱和配對碼。
